# Halloween Parallax Effect 🎃👻

A spooky-themed **parallax scrolling web page** built with **HTML**, **CSS**, and **JavaScript**. This project features layered animations and a haunted design ideal for Halloween landing pages or seasonal events.

## 🔗 Live Demo

[View Live](https://prakashrpk.github.io/heloween---perallex-effect/)  

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3** (for layout and effects)
- **JavaScript** (for parallax movement)

---

## 👻 Features

- Smooth parallax scroll animation
- Halloween-themed assets (ghosts, moon, bats, etc.)
- Layered 2.5D effect for depth
- Responsive layout
